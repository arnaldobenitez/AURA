Estados permitidos en v1.0: `proposed`, `accepted`, `superseded`, `deprecated`, `rejected`.

Un ADR aceptado no se reescribe para borrar su historia. Si cambia la decisión, crear otro ADR que lo referencie y marcar el anterior como `superseded`.
