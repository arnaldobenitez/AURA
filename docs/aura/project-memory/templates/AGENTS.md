# Instrucciones del proyecto

Este proyecto utiliza `AURA_PROJECT_MEMORY v1.0`.

1. Ejecutar `aura agent bootstrap` para descubrir el contexto estructurado del proyecto.
2. Leer `AURA.md` y el Core de Project Memory (`.aura/project.json`, `docs/00-PROYECTO.md`, `docs/01-ESTADO-ACTUAL.md`).
3. Seguir `AURA_AGENT_CONTRACT v1.0` (`docs/aura/AURA_AGENT_CONTRACT_v1.0.md`) para abrir, trabajar, actualizar documentación y cerrar sesiones.

`AGENTS.md` es un adaptador de descubrimiento; `AURA.md`, el Core y `AURA_AGENT_CONTRACT` son la referencia del proyecto.
